# Security Policy

Please do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository when available. Otherwise, contact the Craftmatrix-Codex maintainers privately through the organization's GitHub profile with `Clusterverse security report` in the subject.

Include reproduction details, the affected version or commit, and a safe description of impact. Never include credentials, private keys, kubeconfigs, or other secrets.
