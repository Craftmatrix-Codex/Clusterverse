# Contributing to Clusterverse

Thank you for taking the time to help. Clusterverse is an early project, and thoughtful participation is welcome.

## Before you start

- Check existing issues and discussions before opening a new one.
- For substantial changes, open an issue first so the direction can be discussed.
- Questions and beginner contributions are welcome.

## Issues

Include what you expected, what happened, the Clusterverse version or commit, your K3s/Kubernetes version, and reproduction steps. Remove secrets, tokens, kubeconfigs, and private data before posting.

## Pull requests

1. Create a focused branch from `stable`.
2. Make the smallest coherent change that solves the problem.
3. Add or update tests and documentation where appropriate.
4. Run relevant checks locally.
5. Describe the change and testing in the pull request.

A pull request does not need to be perfect to be useful. If you are unsure, say so; early feedback is better than silent guesswork.

## Review

Reviews are collaboration, not a contest. Please assume good intent, explain reasoning, and keep feedback focused on the work.
